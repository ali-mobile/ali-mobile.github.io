روش انتشار در GitHub Pages:
1) در github.com حساب بساز.
2) یک Repository عمومی با نام USERNAME.github.io بساز.
3) تمام فایل‌ها و پوشه‌های این پروژه را در آن آپلود کن.
4) Settings > Pages را باز کن.
5) Source را Deploy from a branch قرار بده.
6) Branch را main و Folder را / (root) انتخاب و Save کن.
7) پس از انتشار، آدرس سایت: https://USERNAME.github.io

توجه:
این پروژه فرانت‌اند و نمایشی است. برای فروش واقعی، Backend، پایگاه داده، HTTPS، احراز هویت و درگاه پرداخت معتبر لازم است.
